# 🚀 Полное руководство: Как сделать так, чтобы бот работал непрерывно (24/7)

Для того чтобы Telegram-бот работал круглосуточно без остановок, не вылетал при сетевых сбоях и не требовал ручного перезапуска, в проекте предусмотрено несколько готовых решений под разные задачи.

---

## ⭐️ Вариант 1 (Золотой стандарт): Облачный сервер VPS/VDS (Linux / Ubuntu)

Это самый надежный способ для коммерческого использования: сервер работает в дата-центре 24/7/365, не зависит от домашнего интернета, выключения ноутбука или спящего режима.

> **Требования к серверу:** минимальный VPS за 200–350 руб/мес (1 ядро CPU, 1 ГБ RAM, Ubuntu 22.04 или 24.04). Подходят: Timeweb, Beget, Aeza, Selectel, Hetzner и др.

### Способ 1.1: Системная служба Systemd (Рекомендуется)

1. **Подключитесь к серверу по SSH и установите системные пакеты:**
   ```bash
   apt update && apt install -y git ffmpeg curl
   curl -LsSf https://astral.sh/uv/install.sh | sh
   source $HOME/.cargo/env
   ```

2. **Склонируйте или скопируйте файлы проекта в `/opt/telegram-companion-ai`:**
   ```bash
   cd /opt
   # если из репозитория:
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> telegram-companion-ai
   cd telegram-companion-ai
   ```

3. **Создайте и заполните файл окружения `.env`:**
   ```bash
   cp .env.example .env
   nano .env
   # Укажите ADMIN_BOT_TOKEN, ADMIN_TELEGRAM_ID, GEMINI_API_KEY, ELEVENLABS_API_KEY и др.
   ```

4. **Установите зависимости проекта через uv:**
   ```bash
   uv sync
   ```

5. **Активируйте системную службу (готовый файл уже есть в проекте):**
   ```bash
   cp deploy/companion-bot.service /etc/systemd/system/companion-bot.service
   systemctl daemon-reload
   systemctl enable companion-bot
   systemctl start companion-bot
   ```

6. **Полезные команды для управления:**
   - Проверить статус: `systemctl status companion-bot`
   - Смотреть логи в реальном времени: `journalctl -u companion-bot -f`
   - Перезапустить бота: `systemctl restart companion-bot`
   - Остановить: `systemctl stop companion-bot`

*Благодаря параметру `Restart=always` служба сама мгновенно перезапустит бота при любых сбоях или после перезагрузки сервера.*

---

### Способ 1.2: Docker & Docker Compose (В 1 команду)

Если на сервере установлен Docker:
```bash
# 1. Запустить в фоне с автоперезапуском (unless-stopped)
docker compose up -d --build

# 2. Проверить статус контейнера
docker compose ps

# 3. Смотреть логи
docker compose logs -f

# 4. Остановить
docker compose down
```

## 💻 Вариант 2: Запуск на локальном компьютере / сервере Windows

Если вы держите бота на своем компьютере или Windows-сервере, используйте готовые сценарии автозапуска.

### Способ 2.1: Быстрый запуск с интерактивным окном (Auto-Restart Watchdog)
В корне проекта создан файл **`run_bot.bat`**.
- Просто дважды кликните по **`run_bot.bat`**.
- Скрипт запустит бота и войдет в режим бесконечного контроля: если связь пропадет или процесс завершится, он автоматически перезапустит бота через 3 секунды.

### Способ 2.2: Фоновый запуск без черного окна консоли
Если вы не хотите, чтобы на панели задач висело окно командной строки:
- Запустите скрипт **`run_hidden.vbs`** (двойным кликом).
- Бот начнет работать в фоновом режиме Windows в процессах `python.exe` / `uv.exe`.

### Способ 2.3: Автозагрузка при включении Windows (Автостарт)

**Вариант А (Самый простой — через папку «Автозагрузка»):**
1. Нажмите клавиши `Win + R` на клавиатуре.
2. Введите `shell:startup` и нажмите Enter (откроется системная папка автозагрузки).
3. Создайте ярлык для файла **`run_bot.bat`** (или **`run_hidden.vbs`** для фонового запуска без окна) и переместите его в эту папку.
4. Теперь бот будет автоматически включаться сразу при входе в систему.

**Вариант Б (Через Планировщик заданий Windows Task Scheduler):**
1. Откройте PowerShell от имени Администратора.
2. Выполните скрипт автонастройки:
   ```powershell
   cd C:\Users\ildar\.gemini\antigravity\scratch\telegram-companion-ai
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\scripts\setup_windows_task.ps1
   ```
3. Скрипт зарегистрирует задачу `TelegramCompanionAI_24x7`, настроит автозапуск и автоматический перезапуск при падениях каждую минуту.

> ⚠️ **Важное замечание для Windows (Ноутбук / ПК):**
> Чтобы бот не засыпал, откройте:
> *Параметры Windows ➡️ Система ➡️ Питание и спящий режим* и установите для пункта «Спящий режим при питании от сети» значение **«Никогда»**.

## 🛡 Встроенная защита в коде (Self-Healing Loop)

В `main.py` интегрирован двухуровневый контур самовосстановления:
1. **Long Polling Watchdog:** При сетевых разрывах или таймаутах Telegram API бот не падает с ошибкой, а выдерживает адаптивную паузу и продолжает опрос.
2. **Crash Recovery Loop:** Если произойдет непредвиденный фатальный сбой сессии или сокета, ядро бота перехватывает ошибку, освобождает ресурсы и перезапускает сессию через безопасный интервал с экспоненциальным backoff (2с ➔ 4с ➔ 8с ➔ 30с), предотвращая падение процесса.
