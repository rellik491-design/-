## 🎯 1. О проекте и бизнес-логике

Проект представляет собой интеллектуальную платформу-автоответчик для Telegram от лица привлекательной девушки («Алина» и др.) с индивидуальной привязкой к владельцам (`owner_id`), созданную для прогрева входящего трафика, естественного общения и выявления целевых лидов на свидания или квесты.

### 4 Ключевых правила системы:
1. **Реалистичные тайминги переписки:** имитация живого человека (задержка чтения, двойные галочки `✓✓`, реалистичный статус набора текста `typing` пропорционально длине ответа).
2. **Естественный характер без кринжа:** скромное и сдержанное начало общения, запрет на допрос и душную инициативу. Многоступенчатая воронка перед встречей (раскачка 8–15 сообщений -> проверка интереса -> только потом квест).
3. **Голосовые сообщения (ГС) с «эффектом банки»:**
   - Высокая стабильность ElevenLabs (`stability=0.78`, `similarity_boost=0.75`, `style=0.0`, `use_speaker_boost=False`).
   - Замена `!` на `.` перед синтезом, чтобы убрать неестественную бодрость.
   - Аудиофильтр `ffmpeg` (полоса 200–3400 Гц, коробочный телефонный резонанс, сжатие битрейта).
4. **Привязка к владельцу (`owner_id`):** каждый пользователь бота имеет свой профиль анкеты (легенду, город, часовой пояс, стиль общения) и подключенные Telegram-аккаунты.

## ⚡️ 3. Ключевые модули и архитектурные решения

### 3.1. Распознавание речи (STT) — `stt_service.py`
- Бот принимает голосовые сообщения (`.ogg Opus`) и аудиофайлы.
- Автоматически отправляет аудио в мультимодальный Gemini (`gemini-flash-lite-latest` / `gemini-3.8-flash`) с промптом точной транскрибации речи.
- Резервный фоллбэк: Groq Whisper (`whisper-large-v3-turbo`) и OpenAI Whisper.
- Позволяет заполнять анкету девушки **голосом**: админ или пользователь наговаривает войс («Меня зовут Алина, 22 года, живу в Казани...»), и ИИ раскладывает параметры в БД.

### 3.2. Генерация войсов и звук «из банки» — `voice_service.py`
- В ElevenLabs выставлены параметры `stability=0.78, similarity_boost=0.75, style=0.0, use_speaker_boost=False`.
- Перед отправкой текста в TTS все знаки `!` заменяются на `.`.
- Аудио пропускается через FFmpeg:
  ```text
  highpass=f=200, lowpass=f=3400, equalizer=f=1200:t=q:w=1.2:g=5, afftfilt=real='hypot(re,im)*sin(0)':emo=none, volume=1.1
  ```
  Это дает аутентичное глуховатое звучание быстро записанного войса с телефона на улице или дома.

### 3.3. Анти-галлюцинации времени — `timezone_service.py` & `ai_service.py`
Перед каждым запросом к Gemini в системный промпт инжектируется блок:
```text
[СИСТЕМНАЯ ИНФОРМАЦИЯ: Сейчас в твоем городе {city} точное время: {current_time}, день недели: {day_of_week}. Ты находишься здесь и живешь по этому времени. Ошибаться во времени КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО].
```
В промпте жестко запрещены роботизированные отговорки («я вечно путаюсь со временем», «загналась что-то»).

### 3.4. Перехват управления лидами — `handover_service.py`
- В алертах о встрече владелец получает инлайн-кнопку **«✅ Принял лида (Остановить ИИ)»**.
- При нажатии статус `ai_active` переводится в `False`, спам-уведомления прекращаются, а кнопка меняется на **«🤖 Вернуть ИИ (Включить обратно)»**.
- Если владелец сам пишет собеседнику, ИИ автоматически берет паузу.

### 3.5. Панель супер-админа: учет подписчиков и аккаунтов
- В меню админа доступна кнопка **«👥 Подписчики и Аккаунты»**.
- Отображает реальное число активных пользователей, их тарифы, дату окончания подписки и количество подключенных рабочих аккаунтов на каждого.

## 🛠 4. Инструкция по запуску и разработке

### Быстрый старт (рекомендуется через `uv`):
```powershell
# 1. Установка uv (если еще не установлен)
# Windows:
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
# Linux / macOS:
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. Переход в папку проекта и синхронизация виртуального окружения
cd telegram-companion-ai
uv sync

# 3. Настройка переменных
copy .env.example .env
# Отредактируйте .env, указав ваши токен бота и ключи API

# 4. Запуск всех тестов (56 тестов)
uv run pytest

# 5. Запуск живого бота
uv run python main.py
```

### Альтернативный запуск через классический `pip`:
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux:
source .venv/bin/activate

pip install -e .
pytest
python main.py
```

## 💡 5. Что можно улучшить или доработать дальше (Roadmap)

1. **Web-панель управления (FastAPI + React/Vue):**
   - Сейчас всё управление (статистика, анкеты, войсы) доступно через Telegram-бота. Можно развернуть легкий дашборд для наглядного просмотра воронки.
2. **Расширение библиотеки Voice Pack:**
   - Добавление готовых предзаписанных голосовых кружков и войсов на популярные фразы («сейчас бегу по делам», «только проснулась»).
3. **Интеграция дополнительных платежек:**
   - В `subscription_service.py` и `config.py` заложен фундамент CryptoBot. Можно подключить ЮKassa, Stars или Robokassa.
4. **Автоматическая смена прокси для MTProto:**
   - Если используется большое количество Userbot-аккаунтов на одном IP, можно добавить пул SOCKS5/MTProxy в `AccountSession`.
