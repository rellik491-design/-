# 🌸 Telegram AI Companion & Lead Setter

Умный AI-компаньон для Telegram на базе **Telethon (MTProto)**, **Telegram Bot API**, **Google Gemini**, **ElevenLabs** и **SQLAlchemy Async**, работающий от лица девушки с поддержкой:
- 🕒 **Учета реального времени и часовых поясов:** Девушка и собеседник ориентируются по своему времени, бот никогда не пишет ночью и не путает дни недели.
- 🗣 **Распознавания речи (Speech-to-Text):** Входящие войсы от мужчин мгновенно транскрибируются нейросетью и понимаются ИИ. Заполнение анкеты легенды доступно голосом.
- 🎙 **Реалистичных голосовых сообщений (TTS) с «эффектом банки»:** Звук глуховатый и естественный, как с обычного микрофона смартфона на улице или дома, без студийного блеска и театральной интонации.
- 🛡️ **Анти-спама и реалистичных таймингов:** Имитация чтения, две галочки (`✓✓`), задержка набора текста `typing` соразмерно длине фразы.
- 💬 **Многоступенчатой плавной воронки:** Никаких предложений встречи или квеста сходу. Глубокое узнавание интересов (8–15 сообщений) перед любым шагом к свиданию.
- 🔥 **Перехвата встреч (Handover / Lead Gen):** Если собеседник зовет на кофе или свидание, бот фиксирует лида и мгновенно шлет тревожное уведомление владельцу с кнопками «Принял лида (Остановить ИИ)» и «Вернуть ИИ».
- 👥 **Привязки к владельцу (`owner_id`) и мульти-аккаунтам:** Индивидуальные тарифы (7, 14, 30 дней), независимые анкеты, просмотр всех подписчиков и их сессий в панели админа.
- 📊 **Аналитики и базы лидов:** Подсчет сообщений, конверсии во встречи, список лидов с текстом предложений и ссылками.

## 🏗️ Архитектура проекта

```text
telegram-companion-ai/
├── src/
│   └── companion/
│       ├── config.py                 # Pydantic настройки и переменные окружения
│       ├── models/
│       │   ├── db.py                 # Async SQLAlchemy engine & session maker
│       │   ├── enums.py              # AccountStatus, ContactStatus, PlanDuration
│       │   └── entities.py           # Таблицы: User, Subscription, Persona, Contact, AccountSession, VoicePack
│       ├── services/
│       │   ├── ai_service.py         # Gemini API, анти-галлюцинации времени, стили, воронка
│       │   ├── stt_service.py        # Распознавание речи (STT) из войсов
│       │   ├── voice_service.py      # Синтез голосовых ElevenLabs + FFmpeg «эффект банки»
│       │   ├── timezone_service.py   # Вычисление времени в городах, режим сна
│       │   ├── handover_service.py   # Передача диалога владельцу (стоп/старт ИИ)
│       │   ├── account_service.py    # Мульти-аккаунты и админ-сводка по подпискам
│       │   ├── intent_service.py     # Детектор предложений встреч и стоп-слов
│       │   ├── subscription_service.py # Управление тарифами (7, 14, 30 дней)
│       │   ├── reengagement_service.py # Фоновые касания ("как ты?") при молчании
│       │   └── stats_service.py      # Сводка, метрики и список лидов
│       └── bot/
│           ├── telegram_bot_engine.py # Главный управляющий бот и визард анкеты
│           ├── business_bot.py       # Telegram Business интеграция аккаунтов
│           ├── userbot_handler.py    # Пайплайн обработки сообщений Telethon
│           └── admin_notifier.py     # Отправка алертов о встречах с инлайн-кнопками
├── tests/                            # 56 всесторонних pytest-тестов (100% pass)
├── deploy/                           # Готовые файлы службы systemd
├── main.py                           # Точка запуска живого сервера
├── pyproject.toml                    # Зависимости проекта
└── .env.example                      # Шаблон конфигурации
```

## 🚀 Быстрый старт

### 1. Установка зависимостей (через `uv`)
```powershell
cd telegram-companion-ai
uv sync
```

### 2. Запуск всех тестов (56 тестов)
```powershell
uv run pytest
```

### 3. Запуск живого сервера бота
```powershell
uv run python main.py
```

## ⚙️ Конфигурация (`.env`)

Скопируйте шаблон:
```powershell
copy .env.example .env
```
Заполните обязательные переменные: `ADMIN_BOT_TOKEN`, `ADMIN_TELEGRAM_ID`, `GEMINI_API_KEY`, `ELEVENLABS_API_KEY`.
